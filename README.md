# PDF Notes App — Tablet

Планшетное Android-приложение для просмотра PDF, аннотаций, заметок/конспектирования и конвертации страниц PDF в JPG.

Проект подготовлен для сборки через GitHub Actions без Android Studio.

## Сборка APK

Откройте **Actions → Build PDF Notes App → Run workflow**. Workflow распакует подготовленный проект, установит Gradle 8.7 и соберёт debug APK. Результат появится в Artifacts как `PdfNotesApp-debug-apk`.

## Важно

Исходный проект упакован в `PdfNotesApp_tablet.zip.b64`, чтобы его можно было восстановить непосредственно на GitHub Actions. Это технический способ загрузки через подключённый GitHub-инструмент; после запуска workflow APK будет доступен как artifact.

## Что входит в MVP

- интерфейс под планшеты с NavigationRail;
- импорт PDF через системный файловый пикер;
- список документов с поиском и режимами grid/list;
- просмотр PDF;
- хайлайты и заметки поверх страниц;
- экран конспектирования;
- PDF → JPG;
- экран PDF-инструментов;
- настройки;
- GitHub Actions для автоматической сборки APK.

Расширенное редактирование PDF, OCR/ИИ-конспектирование, merge/split/compress/protect/watermark остаются следующими этапами разработки.
